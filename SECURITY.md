# Security Policy

CalMirror runs entirely on your Mac and never sends data over the network,
but it does read and write your calendars. If you find a way for it to expose
calendar data, modify events it should not touch, or otherwise misbehave in a
way that affects security or privacy, please report it privately rather than
in a public issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the **Security** tab of the
repository and choose **Report a vulnerability**. If that option is not
available to you, email thomas@gravitek.io instead.

Please include:

- a description of the issue and its impact,
- steps to reproduce it,
- the CalMirror version (`calmirror version`) and macOS version.

You will get an acknowledgement within a few days. Once a fix is available a
new release is published and the report is credited, unless you prefer to
stay anonymous.

## Supported versions

Only the latest release receives security fixes.
